# AniScore

Instantly see anime ratings from AniList on your favorite streaming sites
and databases.

## Supported Websites

On from install:

- [Anizm.net](https://anizm.net/)
- [TRanimeizle](https://www.tranimeizle.live/)

Turn on from the side panel:

- [Acheriya](https://acheriya.com/)
- [AnimeciX](https://animecix.tv/)
- [AnimeX](https://www.animex.club/)
- [AnimeXe](https://animexe.com/)
- [AnimPow](https://animpow.com/)
- [Asya Animeleri](https://asyaanimeleri.top/)
- [OpenAnime](https://openani.me/)
- [SonAnime](https://sonanime.com/)

Any other site can be added from the browser, without code: right-click a page of it and choose **Integrate this site
with AniScore** (see [Add a Site](https://aniscore.link/guide/add-a-site)).
