# {frontmatter.title}

AniScore displays rich anime metadata from AniList directly on streaming site cards.

## What's Displayed

### Scores & Popularity

Each anime card shows the AniList community score and popularity data. Trending anime are highlighted with a special indicator so you can quickly spot what's hot this season.

### Genres

Genre labels appear below the score, giving you an instant overview of the anime's categories. You can customize the color of each genre label through the side panel settings.

### Tags

AniList's detailed content tags (up to 5 per anime) are also displayed. Like genres, tag colors are fully customizable.

## Data Source

All data comes from the [AniList GraphQL API](https://anilist.gitbook.io/anilist-apiv2-docs/). AniScore uses an offline anime database from [cedya77/anime-offline-database](https://github.com/cedya77/anime-offline-database), falling back to [athanasso/anime-offline-database](https://github.com/athanasso/anime-offline-database), for fuzzy title matching, then fetches detailed information from AniList.

AniScore downloads that database as a ready-made index from this site, which builds it daily: about 5 MB, against about 60 MB for the source database. The index (`anime-index-v1.json` and its file) is a derived database, shared under the same [Open Database License](https://opendatacommons.org/licenses/odbl/1-0/), with contents under the [Database Contents License](https://opendatacommons.org/licenses/dbcl/1-0/), and builds on [manami-project/anime-offline-database](https://github.com/manami-project/anime-offline-database). When the site is unavailable, AniScore downloads the source database instead.

This two-step approach ensures accurate matching even when streaming sites use different title formats or romanizations.
